Notes & Methodology
Latency measurements recorded via time.perf_counter() on Raspberry Pi (Linux). All values converted from microseconds to milliseconds for display. The 95th percentile (P95) represents the worst-case realistic latency: 95% of events complete faster than this value. Standard deviation reflects timing consistency; elevated values warrant mechanical inspection. Median is reported alongside mean as a more robust central tendency estimate in the presence of outliers.
Bimodal Diagnostic: If Figure 3 shows two distinct peaks, run vcgencmd get_throttled on the Pi to check for thermal throttling. A return value of 0x0 rules out throttling; investigate positional motor friction instead.
